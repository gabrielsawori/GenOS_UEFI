# Dokumentasi GenOS

Folder ini berisi dokumentasi utama untuk GenOS v3. Tujuannya adalah agar pengembang, kontributor, dan pengguna dapat memahami arah proyek, arsitektur kernel, fitur yang tersedia, serta cara berkontribusi.

Dokumentasi ini juga disusun agar bisa digunakan sebagai referensi untuk pelatihan AI yang ingin mengenal GenOS.

## Isi folder

- `roadmap.md` - fase pengembangan, milestone, dan peta jalan GenOS.
- `architecture.md` - arsitektur kernel, subsistem utama, alur boot, dan struktur modul.
- `features.md` - daftar fitur saat ini dan yang direncanakan.
- `contributing.md` - panduan kontribusi, pelaporan bug, dan cara kerja tim.
- `bugfix-guidelines.md` - alur bugfix, debugging, dan validasi perbaikan.
- `development-plan.md` - rencana kerja selanjutnya, milestone mini, dan tugas prioritas.
- `ai-training.md` - panduan untuk menggunakan dokumentasi ini sebagai sumber latihan AI.

## Cara menggunakan dokumentasi

1. Baca `roadmap.md` untuk memahami tahapan pengembangan dan prioritas fitur.
2. Baca `architecture.md` untuk mempelajari struktur internal kernel dan komponen penting.
3. Baca `features.md` untuk mengenali fitur yang sudah ada dan yang sedang dikembangkan.
4. Jika ingin berkontribusi atau melaporkan bug, buka `contributing.md`.
5. Untuk pelatihan model AI atau pembuatan dataset, gunakan `ai-training.md`.
